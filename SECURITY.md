# Security

AgentMesh runs other CLIs on your machine and writes into git worktrees, so
security reports are welcome.

**Report privately:** GitHub → Security → "Report a vulnerability" on this repo.
Please do not open a public issue for a vulnerability.

Useful to include: version (`agentmesh --version`), OS, minimal steps to reproduce,
and what an attacker could do.

Supported: the latest release and `main`.
