# Examples

- `flutter-backend/` — what `agentmesh init --auto` generated for a Flutter app with a FastAPI `backend/`
  (9 roles, workflow, project.yaml, CLAUDE.md managed section). Generated from a tiny synthetic repo; read it to see
  the Agent Pack shape before running init on your own project.
- `agents.yaml` — register an extra CLI through the generic adapter (no code).
