# .agentmesh

Project layer of [AgentMesh](https://github.com/). Generated by `agentmesh init`; safe to edit.

| Path | Commit? | What |
|---|---|---|
| `project.yaml` | yes | detected facts + routing/fallback policy (human sections are preserved on re-init) |
| `workflow.yaml` | yes | conditional stage flow |
| `agents/*.md` | yes | one role per file (edited files are never overwritten) |
| `references/index.md` | yes | pointers to reference material |
| `tasks/`, `reports/` | optional | task + result JSON; commit if you want an audit trail |
| `runtime/`, `logs/`, `state/` | **no** | scratch, worker logs (redacted), cooldown state |
| `../.agentmesh-worktrees/` | **no** | one git worktree per write task |

No credentials are stored here. Workers use their own CLI logins.
